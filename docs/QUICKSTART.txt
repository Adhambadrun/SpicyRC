SPICY LAMAR — RINGCENTRAL IN-APP QUICKSTART
=============================================

Spicy Lamar controls now live inside RingCentral itself.

INSTALL (Windows)
1. Close RingCentral.
2. Run build.bat in the repository root.
3. The installer finds RingCentral (or provide -Source to
   ringcentral-patch\apply-patch.ps1), backs up resources\app.asar,
   installs the in-app engine, repacks it, and starts RingCentral.
4. Open the RingCentral dialer.

CONTROLS INSIDE RINGCENTRAL
  🌶 SPICY ON/OFF                  next to RingCentral's CALL control
  Spicy Lamar — Auto-Answer        in RingCentral's Settings menu
  Pin RingCentral on top            in RingCentral's Settings menu

SAFETY BOUNDARY
  * No standalone Spicy Lamar window or EXE is launched.
  * No global hotkey, Alt+F1 sequence, SendInput, keyboard hook, or focus
    change is installed.
  * Auto-answer clicks only a visible Answer/Accept control on a visible
    incoming-call surface in RingCentral.
  * DTMF/call helpers use only RingCentral's own keypad, field, and Call
    control.
  * Pin affects only the RingCentral Electron BrowserWindow.

IF THE BUTTON IS MISSING
  Open RingCentral DevTools, look for [SpicyLamar] messages, tune selectors
  in ringcentral-patch\spicy-engine\spicy-config.js, rerun build.bat, and
  restart RingCentral.

RESTORE
  Close RingCentral and restore resources\app.asar.bak over app.asar.

build_portable.bat and build_standalone.bat redirect here intentionally so
there is no supported path that creates a separate desktop control window.
