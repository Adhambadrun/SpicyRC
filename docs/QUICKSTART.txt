🌶️ SPICY LAMAR v1.0 Integrated — QUICKSTART
═══════════════════════════════════════════════════════════

WHAT IT DOES:
One window (980x620) hosts RingCentral Phone inside. No second
"keypad is now open in a new window" popup — the keypad is docked
right as a panel. Left shows telemetry + logs. Top settings bar
drives everything.

TURBO ENGINE (default):
  * 200Hz poll (5ms) — throttled 100ms poll floor / 50ms storm floor
  * WindowCache + CollectRingCentralWindows (title OR process name
    ringcentral/glip/rcdesktop) — fires to every popup
  * 6-shot Alt+F1 cascade (PostMessage to main+child Intermediate D3D
    + SendInput + WM_COMMAND, NEVER WM_SYSCHAR or Alt+A)
  * DTMF: WM_CHAR to main+child + SendInput UNICODE if foreground is RC
  * MMCSS Pro Audio + 0.5ms NT timer + HIGH priority

INSTALL:
1. Build it: build_portable.bat (C++ TURBO) or build.bat (C#).
2. Copy "SpicyLamar.exe" anywhere.
3. Double-click to run. Single window appears. No admin, no UAC.
4. If SmartScreen warns: More info -> Run anyway, or Unblock.

HOTKEYS & KEYS:
F8  : Self-test (forces Alt+F1 cascade, logs PASSED)
F9  : Show/Hide dashboard
F11 : Pause/Start  (also PAUSE pill + tray menu + tooltip)
F12 : Exit
Type 0-9*#+ : append + SendDtmf (logs KEYPAD: sent DTMF 'x')
Enter     : CALL — SendDialString(buffer) + TryAnswer(CHAN_KEYPAD)
Backspace : delete last digit
Esc / END : send VK_ESCAPE + clear buffer
Pin toggle: SetWindowPos TOPMOST ↔ NOTOPMOST
Reattach  : logs "Keypad reattached inside dashboard (no popup)." (no new HWND)

VERIFY:

  → checks PE32+ x64 GUI, icon, version 1.0 Integrated, no popup string
