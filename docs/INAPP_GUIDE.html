🌶 Spicy Lamar · now a feature INSIDE RingCentral

build.bat was previously a compiler for a separate 980×620 "SpicyLamar.exe" demo window — but running it opened nothing because that isn't what you wanted. This version patches RingCentral's own app so the feature lives inside it, then launches RC.

Why build.bat didn't open anything: it needed your RingCentral app files to patch, and none were found next to the repo (the original RingCentral.zip on GitHub was a Git-LFS pointer with no object on the server). Drop a real copy in and build.bat will patch + launch it. This page opens so you always see a result.

1 · Give build.bat your RingCentral (any one of these)

  1. Best: copy your unpacked RingCentral folder (one that has RingCentral.exe + resources\app.asar) to the repo root, or
  2. place a RingCentral.zip of it in the repo root or in ringcentral-patch\, or
  3. do nothing extra — if RingCentral is already installed under %LocalAppData%\RingCentral, build.bat auto-detects it.

Then just double-click build.bat. It unpacks app.asar, injects the feature, repacks, and launches the patched RingCentral.

3 · Features (now in-app)

FeatureIn-app behaviour
Auto-answerDetects an incoming call and clicks RC's own Answer control. Toggle via the 🌶 SPICY button or the ⚙ menu.
DTMF / dialDrives RC's own keypad / number field (send digits from the SPICY flow).
Pin on topspicy-main.js mirrors the old top-most behaviour with setAlwaysOnTop.

4 · If no 🌶 button appears after first launch

RingCentral is proprietary and its DOM classes vary by version. Open the dialer's DevTools (Ctrl+Shift+I), read the [SpicyLamar] console logs, then tune selectors in ringcentral-patch\spicy-engine\spicy-config.js and re-run build.bat.
